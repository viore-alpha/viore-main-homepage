# AlphaWing Motion

Viore/Alphadoc homepage handoff package.

- Main file: `alphawing-motion.html`
- Frame spec: PC 840 x 560px, Mobile 390 x 450px, mobile min height 430px
- Assets are bundled under `assets/brand/` and referenced with relative paths.
- Content uses generated public-demo data, not real user/community/article data.

Open `alphawing-motion.html` directly or serve this folder from a static server.
